# Оптимизация запроса 1С

1. Найди запрос: прикреплённый код, выделение или модуль, который назвал
   пользователь (`read_module`, `search_code` по «ВЫБРАТЬ»). Прочитай метод
   целиком: откуда берутся параметры и что делается с результатом.
2. Проверь по списку и для каждой находки укажи Модуль:строка, чем плохо и
   как исправить:
   - **Запрос в цикле** — главный убийца скорости. Собери ключи в массив или
     таблицу значений и сделай один запрос (`В (&Список)` или временная
     таблица из параметра-таблицы).
   - **Обращение через точку к реквизитам ссылок в цикле** (в коде:
     `Ссылка.Контрагент.ИНН` на каждой итерации) — чтение объекта на каждый
     шаг. Выбирай нужные поля в запросе. В самом запросе точка нормальна
     (скилл query-style), кроме полей составного типа — там `ВЫРАЗИТЬ`.
   - **Виртуальные таблицы**: отбор — в параметрах (`Остатки(&Дата,
     Номенклатура В (&Список))`), а не в `ГДЕ`; период указан.
   - **Подзапросы в условиях соединения** и `ИЛИ` в соединениях — замени
     временными таблицами (`ПОМЕСТИТЬ`; `ИНДЕКСИРОВАТЬ ПО` — только для
     большой ВТ, по которой соединяют) или `ОБЪЕДИНИТЬ ВСЕ`.
   - **Соединение с подзапросом / виртуальной таблицей** без отбора —
     сначала временная таблица с нужными записями.
   - Условия, которые не используют индекс: функции над полем
     (`ГОД(Дата) = 2026`, `ПОДСТРОКА`), `ПОДОБНО "%…"` — переписать на
     диапазон или отбор по индексируемому полю.
   - `ВЫБРАТЬ *`, лишние поля, `РАЗЛИЧНЫЕ` без нужды, сортировка, которую
     никто не использует.
   - `ПЕРВЫЕ` без `УПОРЯДОЧИТЬ ПО` там, где важен порядок.
   - Ограничения доступа: нужен ли `РАЗРЕШЕННЫЕ`.
3. Перепиши запрос целиком в блоке кода `bsl` по стилю query-style, с
   короткими комментариями к изменённым местам. Если меняется код вокруг (цикл → один запрос) —
   покажи и его.
4. Оцени эффект словами («один запрос вместо N», «отбор в индексе
   регистра») и скажи, что проверить: те же результаты на тестовых данных,
   замер в Замере производительности.

Модуль не правь, пока пользователь не попросит применить изменения.
