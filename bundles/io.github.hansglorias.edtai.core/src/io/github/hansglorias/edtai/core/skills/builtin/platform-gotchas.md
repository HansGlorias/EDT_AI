# Грабли платформы 1С, БСП и типовых

Проверено на практике (платформа 8.3.2x, БСП 3.x). Если в другой редакции
поведение отличается — скажи об этом.

## Язык и типы

- **Режим совместимости ограничивает язык.** Платформа 8.3.27 в режиме 8.3.16
  не знает `ХешированиеДанных.ХешСуммаСтрокой` (замена: `ХешСумма` плюс
  `ПолучитьBase64СтрокуИзДвоичныхДанных` или перевод в hex). Перед свежим
  методом смотри `<compatibilityMode>`.
- **Директива компиляции действует на одно объявление.** `&НаКлиенте` перед
  блоком `Перем` делает клиентской только первую переменную.
- **Локальная переменная с именем свойства формы или объекта пишет в
  свойство** (скилл bsl-style, п. 4).
- **Значения в кэшах и данных формы бывают `ДанныеФормыСтруктура`, а не
  `Структура`.** Проверка `ТипЗнч(Х) = Тип("Структура")` отсечёт всё. Проверяй
  `Х.Свойство("Поле")`.
- **NULL из левого соединения.** `Запрос.Выгрузить()` сохраняет NULL. У такой
  колонки NULL входит в описание типа, поэтому
  `Колонка.ТипЗначения.ПривестиЗначение(Null)` вернёт Null. Сперва вычти тип:
  `Новый ОписаниеТипов(Колонка.ТипЗначения, , МассивСТипомNull)`.
- **HMAC в платформе нет.** HMAC-SHA256 собирается из `ХешированиеДанных`
  (`ХешФункция.SHA256`), `БуферДвоичныхДанных` и `ПобитовоеИсключительноеИли`
  (ipad 0x36, opad 0x5C, блок 64 байта); сверяй с векторами RFC 4231.
- `ПрочитатьДанныеИзБезопасногоХранилища` для отсутствующего ключа возвращает
  `Неопределено`, а не пустую строку.
- EDT показывает недоступность методов по контексту
  (`ТекущаяУниверсальнаяДата()` в клиентском коде — `undefined-function`):
  смотри ошибки своих строк без фильтра важности.

## Формы

- **Имя формы:** `"Справочник.X.ФормаОбъекта"` (по виду) или
  `"Справочник.X.Форма.ФормаЭлемента"` (по имени, через `.Форма.`).
  `"Справочник.X.ФормаЭлемента"` не существует.
- **`Отказ = Истина` в `ПриОткрытии` убивает форму раньше, чем откроется
  другая:** ни `ОткрытьФорму`, ни `ПоказатьЗначение` его не переживают.
  Переадресация — только через `ПодключитьОбработчикОжидания`; лучше делать
  переход там, откуда открывают.
- Подменяя форму в `ОбработкаПолученияФормы` на форму другого объекта, меняй и
  `Параметры.Ключ`.
- **Основная таблица динамического списка** иногда слетает в `Form.form`: ключ
  строки перестаёт быть ссылкой, кэш по ключу даёт дубли.
- `ЗначенияЗаполнения` игнорируются без «Заполнять из данных заполнения».
- Отбор динамического списка в новый элемент платформа не переносит:
  передавай `ЗначенияЗаполнения` явно.
- `ВводДоступен()` ложь, пока поверх открыта блокирующая форма: прямой вызов
  перерисовки из оповещения теряется.
- Клиентская `ТекущаяДата()` и серверные даты расходятся: сравнивай даты одного
  источника.

Поле HTML — скилл html-field.

## БСП

- **РЛС считается по каждой группе доступа отдельно** (скилл access-rights).
- Регистрация объекта в `ПриЗаполненииСписковСОграничениемДоступа` обязывает
  написать `ПриЗаполненииОграниченияДоступа` в модуле менеджера.
- **Служебным пользователям БСП роли из профилей не разворачивает.**
- **Обработчики обновления запускаются только для версий новее записанной в
  базе** (скилл release-update).
- **Шаблоны сообщений:** как только у объекта-назначения появился модуль
  менеджера, БСП требует все хуки. Для писем три:
  `ПриПодготовкеШаблонаСообщения`, `ПриФормированииСообщения`,
  `ПриЗаполненииПочтыПолучателейВСообщении` (для СМС ещё телефоны). Без любого
  — «Метод не обнаружен».
- **Начальные настройки интерфейса** новому пользователю — в
  `ПользователиПереопределяемый.ПриУстановкеНачальныхНастроек`, а не правкой
  общих настроек.
- **Файловая база, регламентное задание под техническим пользователем,
  HTTP-запрос через `ПолучениеФайловИзИнтернета`:** «Нарушение прав доступа» —
  чтение настроек прокси требует права Администрирование. На серверной базе
  ветка другая. Административные права в роль не добавлять.
- Любая запись идёт через подписку проверки удаляемых объектов и (при РЛС на
  уровне записей) через ключи доступа: технической роли нужны права чтения
  служебных регистров и констант.
- Очередь почты и задач БП обрабатывается регламентными заданиями:
  «промежуточный статус не ставится» часто значит, что задание ещё не
  отработало.

## Платформенные сервисы

- **`ТокенДоступа` (8.3.21+)** выпускает JWT, проверку делает платформа по
  `accessTokenAuthentication` в `default.vrd`. На битый или истёкший токен
  ответ 402, без 401. Ключом HMAC платформа берёт саму Base64-строку
  `keyInformation`.
- Безопасный режим (HTTP-сервис расширения): не работает привилегированный
  режим, не читается безопасное хранилище, запрещено `HTTPСоединение`.

## Документооборот КОРП 3.0

- `Справочник.ДокументыПредприятия`: `Наименование` не равно заголовку — при
  заполненных номере и дате модуль собирает `Заголовок + " (№ … от …)"`.
  `НайтиПоНаименованию(Заголовок)` молча вернёт пустую ссылку: ищи запросом по
  `Заголовок`.
- Скалярный `Контрагент` не пишется напрямую, он берётся из ТЧ `Контрагенты`
  при записи; а при учёте сторон ТЧ `Контрагенты` очищается без заполненной ТЧ
  `Стороны`. Так же у шаблонов документов. Обе ошибки тихие: сверяй отдельным
  чтением.
- Профили через полномочия сотрудников разворачиваются в роли только у
  неслужебных пользователей со связью с сотрудником; техническому
  пользователю роли выдавай напрямую.
