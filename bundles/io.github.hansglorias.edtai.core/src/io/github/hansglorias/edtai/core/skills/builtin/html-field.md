# Поле HTML документа

## 1. Обмен JS и 1С: опрос из ПриНажатии

Надёжный канал: страница держит состояние и поднимает флаги, 1С забирает их в
обработчике `ПриНажатии` поля (срабатывает на любой клик в HTML) вызовами
методов окна документа.

- Методы читают и сбрасывают флаг за один вызов (`isDoubleClick()` вернул
  истину и обнулил), чтобы событие не обработалось дважды.
- Родной `dblclick` во встроенном движке ненадёжен: двойной клик определяй сам
  (два клика по одной строке в пределах 500 мс).
- Навигационные ссылки строк храни в `data-*`; `getCurrentLink()` отдаёт
  ссылку выбранной строки, 1С открывает её `ПерейтиПоНавигационнойСсылке`.
- Команды контекстного меню страницы и горячие клавиши тоже отдавай
  pull-методами (`getPendingCommand` плюс сброс) с отметкой времени: команды
  старше нескольких секунд отбрасывай. `ДанныеСобытия.Button` ненадёжен: в
  тонком клиенте Linux приходит пустым.
- Окно документа получай заново при каждом обращении, не кэшируй.

## 2. Что решает BSL, что макет

Правила видимости и доступности команд живут в модуле формы: роли, статусы,
типы объектов. Макет получает готовый результат данными и только рисует.
Условия в JS не видны из конфигуратора и не правятся без перезаливки макета.

## 3. Движки

| Клиент | Движок | Следствие |
|---|---|---|
| тонкий, Windows | своя сборка WebKit (уровень Safari 11) | современные SPA не грузятся; осторожный JS без свежих возможностей |
| тонкий, Linux | WebKitGTK | документ появляется асинхронно, нажатия ловятся не всегда; `Элемент.Документ` может «уплыть» на вложенный iframe |
| веб-клиент | браузер пользователя | 1С перехватывает клавиатуру и часть событий, буфер обмена только в защищённом контексте |

- Обращайся к JS только после `ДокументСформирован` и проверяй окно перед
  каждым вызовом.
- **Вложенный iframe в макете** может поднять `ДокументСформирован` со своим
  документом и перехватить `Элемент.Документ` — на Linux ломаются все вызовы
  JS. Встраивай такое отдельным полем.

## 4. Вёрстка высоты

- Абсолютный элемент внутри ячейки (ручка ширины колонки): высота
  фиксированная в px. `height: 100%` в вебе схлопывается в ноль.
- Корень макета: `height: 100%` плюс `display: flex; flex-direction: column`,
  а не `100vh` с абсолютным позиционированием.
- Ширину колонок при ресайзе храни в процентах и задай `min-width` таблице.

## 5. Клавиатура

- Сочетания вешай на команды формы (кнопки в «Ещё»): так они работают в
  тонком клиенте.
- В веб-клиенте 1С слушает `keydown` на document фрейма и гасит всплытие:
  слушай на `window` с `capture: true`, дальше `stopPropagation`. Ctrl+F и F5
  гаси.
- Проверяй `keyCode`, а не `key`: на русской раскладке у Ctrl+F `key` — «а».
- Стрелки — только на странице: команды формы на стрелках отберут их у полей
  ввода.
- Отсекай повтор (около 200 мс).
- Подменять функции окна фрейма из верхнего окна нельзя: 1С падает на каждом
  клике.

## 6. Обновление содержимого

- `ВводДоступен()` ложь, пока поверх открыта другая форма. Обновление по
  оповещению ставь через `ПодключитьОбработчикОжидания`, а не напрямую.
- Отдавай в макет данные, только если они изменились (хеш собранного JSON на
  сервере).
- Даты для сравнения бери обе серверные.
- Тяжёлую сборку делай `&НаСервереБезКонтекста`: в данных формы лежит текст
  макета, тащить его на сервер на каждом тике незачем.

## 7. Буфер обмена в вебе по http

`СредстваБуфераОбмена.ИспользованиеДоступно()` в веб-клиенте по http не на
localhost — Ложь. Обход: маленькая форма с полем HTML, копирование
`document.execCommand('copy')` в документе верхнего окна
(`window.top.document`).
