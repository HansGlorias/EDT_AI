# Комментарии к методам

1. Прочитай метод и места его вызова (`search_code` по имени), чтобы
   понять назначение, типы параметров и результата.
2. Напиши комментарий над методом по стандарту 1С:
   ```bsl
   // Возвращает остаток товара на складе на дату.
   //
   // Параметры:
   //   Номенклатура - СправочникСсылка.Номенклатура - товар.
   //   Склад        - СправочникСсылка.Склады - склад; Неопределено — по всем складам.
   //   Дата         - Дата - на какой момент; по умолчанию — текущая дата сеанса.
   //
   // Возвращаемое значение:
   //   Число - остаток в базовых единицах.
   //
   // Пример:
   //   Остаток = Склад.Остаток(Товар, ОсновнойСклад);
   //
   Функция Остаток(Номенклатура, Склад = Неопределено, Дата = Неопределено) Экспорт
   ```
3. Правила:
   - Первая строка — что делает метод (глаголом), без «Процедура/Функция…».
   - Тип каждого параметра — как в синтаксис-помощнике (`Строка`,
     `Структура`, `ДокументСсылка.Заказ`); у структур — список ключей с
     типами; для необязательных — значение по умолчанию.
   - `Возвращаемое значение` — только у функций.
   - `Пример` — для экспортных методов программного интерфейса.
   - Комментарий не пересказывает код построчно.
4. Выдай комментарии в блоке кода; если пользователь просит вставить —
   правь модуль через `edit_module`, по одному методу.
