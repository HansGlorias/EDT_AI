# Клиент-серверное взаимодействие в форме

1. Прочитай модуль формы (`read_module`) и, если нужно, общие модули,
   которые он вызывает.
2. Найди и опиши («Модуль:строка — проблема — исправление»):
   - **Несколько серверных вызовов подряд** в одном обработчике — объедини
     в один `&НаСервере` или `&НаСервереБезКонтекста` метод, который вернёт
     всё нужное (структурой).
   - `&НаСервере` там, где не нужны данные формы, — замени на
     `&НаСервереБезКонтекста` (не передаётся форма, вызов легче).
   - **Обращение к ссылке через точку на клиенте** (`Объект.Контрагент.ИНН`)
     — неявный серверный вызов; получи значение на сервере или через
     `ОбщегоНазначенияВызовСервера.ЗначениеРеквизитаОбъекта` (если есть БСП).
   - Серверный вызов **в цикле** или в `ПриИзменении` каждой строки, где
     можно один раз.
   - Тяжёлые вычисления на клиенте или интерактив на сервере
     (`Вопрос`, `Предупреждение` — только на клиенте и асинхронно).
   - Синхронные `Вопрос()`, `ОткрытьФормуМодально()` — заменить на
     `ПоказатьВопрос` с `ОписаниеОповещения` или `Ждать` (в новых версиях).
   - Передача на сервер больших коллекций, которые можно получить там
     же; возврат на клиент лишних данных.
   - `&НаКлиентеНаСервереБезКонтекста` для общей логики — где уместно.
3. Для каждой находки — короткий пример исправленного кода в блоке `bsl`.
4. Итог: сколько серверных вызовов было в типовом сценарии и сколько
   станет.
