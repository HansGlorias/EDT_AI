# Значки EDT AI

Единый контурный набор на сетке 16×16: линия 1,35 px, скруглённые концы,
прозрачный фон, без градиентов и теней. Действия — серо-синие `#788596`,
знак плагина и успешное подключение — бирюзовые `#278F95`.
Нейтральный контур читается на светлом и тёмном фоне.

Знак EDT AI — диалог с угловыми скобками кода. Ревью повторяет форму
диалога: крест — ошибка, восклицательный знак — предупреждение,
`i` — информация. Серьёзность различается и цветом, и символом.
В окне «Проблемы» у всех находок общий знак ревью с галочкой;
серьёзность хранится в обычном атрибуте маркера Eclipse.

Исходная геометрия — `tools/GenerateIcons.java`. Из корня репозитория:

```sh
java tools/GenerateIcons.java
```

Нужен только JDK 17, дополнительных библиотек нет. Скрипт обновляет PNG
16×16 и `@2x` 32×32, а также создаёт `target/icon-preview.png` для
просмотра обеих тем. PNG входят в плагин; генератор при сборке не нужен.
