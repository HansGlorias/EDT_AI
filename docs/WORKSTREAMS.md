Срез 03.11.2026, main `8cff4ca` после #90. Это карта продолжения, не требование выполнять всё подряд.

Одна реализация — отдельная ветка/PR; большое направление разбивается на
небольшие изменения, а не переносится целиком в один PR.

Критерии для всех направлений: Windows/Astra, Java 17, Eclipse 4.30,
без сторонних библиотек и обязательного облака. Локально целевые тесты,
полный Windows/Ubuntu verify в CI. Не смешивать незавершённую диагностику
с другими PR. Планирование и анализ документации не требуют Eclipse.

При продолжении сверить main и активные чаты: таблица — снимок состояния,
а не автоматический реестр статусов. Она сохраняет память о направлениях
и точках продолжения, но не обещает полного журнала выполнения или трасс
прошлых задач. Бэклог — в [ROADMAP.md](ROADMAP.md); развитие уже работающей
разведки — в [MULTI_AGENT_RECON.md](MULTI_AGENT_RECON.md). Реальные замеры
полезны для выбора следующих улучшений, но не являются предварительным
условием работы над независимыми направлениями.
