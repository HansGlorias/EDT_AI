Контрольный факт для оценщика S10, не прикреплять к вопросу модели.
Проверяемый тип: Массив, метод Найти(Значение).
Результат: индекс первого найденного элемента; если элемент не найден — Неопределено.
У массива нет метода НайтиПервый. Проверять по синтакс-помощнику установленной
версии платформы или get_platform_documentation с записью версии и результата.
Это рубрика, а не копия документации платформы и не доказательство обращения модели к справке.
